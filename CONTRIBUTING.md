# Contributing

Use issues or pull requests for corrections. Include the product ID, edition,
release or commit, operating system if relevant, primary reference, and proposed
wording. Preserve the distinction between source claims, code observations,
runtime findings, and editorial inference.

Every factual record needs sources and a real review date. Do not infer a
license from public repository visibility or infer missing support from missing
documentation. Declare relevant vendor or maintainer affiliations.

Run `npm run check`, `npm run build`, and `npm test` before submitting.

For runtime evidence, provide a minimal fixture and reproduction steps, exact
versions, expected result, observed result, and relevant warnings. Screenshots
are optional; include rights, capture metadata, alternative text, and a factual
caption if used. Do not contribute confidential or restricted material.
