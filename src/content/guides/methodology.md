## Scope and dates

This demo carries forward 65 entries from an existing comparison and adds BondCraft as P66. It includes desktop applications, browser editors, libraries, wrappers, automation tools, and legacy or unconfirmed candidates. It does not claim to capture every tool in the world.

The site was prepared on **05 November 2026**. Product sources were reviewed on the dates recorded beside each entry, mainly **31 October–04 November 2026**. Preparing this website does not refresh those checks. Release numbers, license terms, and prices can change.

## Evidence labels

- **Source review:** a feature or condition was described in an official product page, author statement, repository, license, or reviewed code. All current entries use this level.
- **Not established:** the reviewed material did not settle the question. This never means “unsupported.”
- **Hands-on pending:** no independent runtime or file round-trip result has been recorded for this demo.

Repository visibility, a feature checklist, and a successful build of this website do not establish software quality or chemical correctness. No measured performance ranking, compatibility certification, or star-count ranking is presented.

## Source selection

Prefer original product documentation, release artifacts, license files, source repositories, and statements by the creator. Keep primary URLs next to the product. Use immutable commit links for code observations when available. Distinguish a repository's current branch from a published release and record contradictions instead of silently resolving them.

Prices describe a dated region, edition, plan, and eligibility condition. No currency conversion or cross-plan price ranking is performed. A “free” product is not automatically open source, commercially usable, or redistributable.

Original Japanese research notes are retained in the directory. English comparison summaries are editorial condensations; the primary sources govern factual interpretation. The complete source index includes supplemental documentation as well as per-product references.

## Reproducible testing

The [20-task benchmark plan](../benchmarks/) records the proposed tests. All results are pending. The [comparison demo](../comparison/) summarizes ten selected workflow profiles.

Record the product version and commit, operating system, build or distribution, configuration, and network state. Keep the starting document, exported document, reopened document, and a clear definition of success. Separate rendering quality from chemical graph correctness.

For timing tasks, allow a practice run, repeat the task three times, counterbalance the product order, and report the median with the input method and operator recorded. Do not compare an experienced user's favored tool against an unfamiliar tool without stating that condition.

For compatibility tasks, inspect both visual layout and chemical semantics. Report simplification warnings, explicit rejection, silent loss, and successful preservation separately.

## Corrections and contributions

Include the product, version or commit, affected statement, primary source, and a precise proposed correction. Runtime claims should include reproduction steps and test files. Never upload confidential chemistry, proprietary documents, personal data, or license-restricted assets.
